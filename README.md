Leonida Trophy Atlas: the best GTA 6 trophy guide. All 55 PS5 trophies with official names, descriptions and grades, a cited guide in the app's own words per trophy, a tracker with search, filters, spoiler mode and export/import, a 3-step platinum roadmap, a missables page, and a sources and method page. Offline static web app, no build step.

## Run it

```sh
node serve.ts
```

Serves `app/` on http://localhost:8080 (`--port <n>` for another port).
